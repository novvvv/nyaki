# 폰트

## x10y12pxDonguriDuel (どんぐりデュエル)

10×12 픽셀 그리드로 만든 일본어 픽셀 폰트.

| | |
|---|---|
| 제작 | hicc — Copyright (c) 2025 |

| 소개 | https://fontfree.me/3391 |
| 버전 | 2025-01-10 |
| 형식 | TrueType (40KB) |

### 라이선스

배포처 규약 기준 **상업 이용 가능 · 크레딧 선택 · 재배포 가능**,
금지되는 것은 **폰트 단독 판매**뿐이다. 웹폰트로 변환해 쓰는 것도 허용된다.

다만 배포처가 신규 폰트는 SIL OFL, 기존 폰트는 자체 규약을 쓴다고 안내하는데
**이 폰트가 둘 중 어디에 속하는지는 명시돼 있지 않다.** 폰트 파일 안에도
라이선스 항목(name table 13·14번)이 비어 있다. 어느 쪽이든 위 조건은 같아서
사용에는 문제가 없지만, **SIL OFL이라면 배포 시 OFL.txt를 같이 넣어야 한다.**
실제로 쓰기로 정하면 배포처에 확인할 것.

### 수록 문자 — 458자

| | |
|---|---|
| 히라가나 | 92 |
| 가타카나 | 95 |
| 영문·숫자·기호 | 95 |
| 일본어 구두점 | 10 |
| **한자** | **0** |
| **한글** | **0** |

**한자와 한글이 없다.** 그래서 본문에는 쓸 수 없다 — UI가 한국어고, 단어에도
한자가 섞인다(`私`, `学生`). 로고·숫자·가나 표기 같은 장식 용도로만 가능하다.

### 쓸 때

`glyf`(외곽선)가 있어서 브라우저에서 렌더된다. 비트맵(`EBDT`)만 있는 픽셀
폰트는 웹에서 안 나오는데 이건 아니다.

픽셀 폰트라 **12px의 배수**(12·24·36…)에서 가장 또렷하다. 그 외 크기에서는
가장자리가 흐려진다.

아직 어디에도 연결하지 않았다. 쓰려면 [layout.tsx](../layout.tsx)에서
`next/font/local`로 불러온다. 그전에 **woff2로 변환**하면 용량이 크게 준다.

```tsx
import localFont from "next/font/local";

const donguri = localFont({
  src: "./fonts/x10y12pxDonguriDuel.ttf",
  variable: "--font-donguri",
});
```
